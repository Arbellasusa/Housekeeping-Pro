Código de sala / Hotel ID
El código identifica tu hotel. Todos los dispositivos con el mismo código se sincronizan automáticamente vía almacenamiento local compartido.
📡 Cómo funciona la sincronización
• Mismo dispositivo: Los datos persisten entre sesiones con localStorage.
• Múltiples dispositivos: Se sincronizan via BroadcastChannel cuando están en la misma red (mismo WiFi del hotel) o mediante el mismo navegador del dispositivo.
• Sincronización en tiempo real: Cada cambio se emite a todos los dispositivos activos instantáneamente.
• Para sincronización total en red: Usa la misma URL con el mismo código de hotel. El sistema detecta automáticamente otros dispositivos activos.
